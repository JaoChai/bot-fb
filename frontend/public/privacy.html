Privacy Policy – Monday Gmail

Last updated: 27 October 2026

Monday Gmail is a private assistant tool used only by the owner of botjao.com (anugooltippon@gmail.com) to manage his own Gmail account. It is not offered to the public.

What data it uses

  • Gmail message metadata and content of the owner's own mailbox (Gmail scopes gmail.readonly and gmail.modify).
  • It is used only to summarise mail for the owner and to move mail the owner has approved to Trash.

How data is stored and shared

  • The OAuth token is stored on the owner's own server and is readable only by the owner's account.
  • Gmail data is not sold, not shared with third parties, and not used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
